Что должно лежать в этой папке
==============================

sha.jar            (обязательно) - собранный мод SHA. Бандлится внутрь
                   alpha_protocol-*.jar (jar-in-jar).
                   Вариант A: скачать артефакт sha-mod-jar из репозитория
                   Crown91/sha_test, переименовать в sha.jar и загрузить сюда.
                   Вариант B: задать секрет SHA_TEST_TOKEN (fine-grained PAT,
                   Actions: read + Contents: read на sha_test) - тогда CI
                   скачает jar сам.

zemlya.jar         (желательно) - собранный мод Zemlya, тоже бандлится внутрь
                   alpha_protocol-*.jar. Нужна АКТУАЛЬНАЯ сборка, в которой
                   com.example.api.GravityChanger содержит isInfected(),
                   infect(), getInfectedGravity(), setGravityAnomalyStrength(),
                   и есть класс com.example.api.GravityAnomalyZone.
                   Если файла нет, сборка возьмёт API из zemlya-api/java, но
                   тогда мод Zemlya придётся ставить в mods отдельно.

sodium.jar,        (обязательно) - внешние моды, только для компиляции.
punchy.jar         Внутрь jar НЕ бандлятся, игрок ставит их сам.

zemlya-1.0.0.jar   НЕ используется: устаревшая сборка без API аномалий
                   гравитации. Можно удалить.
